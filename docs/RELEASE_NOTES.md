## What's new in 0.2.0

Notebooks got three new ways to find and share your notes, plus two fixes that make everyday use smoother.

You can now pull up only the notes that carry a given tag, so a busy notebook stays easy to navigate. You can also search across all your notes by the text they contain, which means you no longer have to remember which note held a particular detail. And when you need to take your notebook elsewhere, you can export it as a JSON string and share or back it up in one step.

We also made two things more reliable. A note no longer keeps duplicate tags, so your tag lists stay clean. And if the notes file is missing, you now get a clear message explaining what went wrong instead of a confusing failure.

Try a tag filter on your busiest notebook first. It's the quickest way to see how much easier things get.
